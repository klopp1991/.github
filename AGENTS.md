# Hinweise zur Bearbeitung dieses Repos

Dieses Repo ist öffentlich. Es darf keine internen Namen, Adressen, Pfade oder Teamregeln enthalten; öffentliche Texte bleiben in Anwendersprache.

Label `sascha`: Eine Rückfrage an den Repo-Inhaber ist offen; die Bearbeitung wartet auf seine Antwort.

Ändert eine Änderung das sichtbare Verhalten (neue, geänderte oder entfernte Vorlage, Bedienung oder Voraussetzung), führen dieselben Commits das README und den Abschnitt „Unveröffentlicht“ in `CHANGELOG.md` nach.
